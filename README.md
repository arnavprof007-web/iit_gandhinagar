# GreenPulse — Mission LiFE Sustainability Platform

**HackCult '26 Track 1: Green Energy & Sustainability**

All frontend source code, assets, configuration, tests, and documentation are located inside the [`frontend/`](./frontend) directory.

### Quick Start
```bash
cd frontend
npm install
npm test
npm run dev
```

For full architecture details, design system, feature checklists, and future FastAPI backend integration guides, refer to [`frontend/README.md`](./frontend/README.md).
